给 **2027 年 12 月初试（2028 届）** 的 11408 全程学习规划与每日打卡页。

- 考试科目：政治 101 / 英语一 201 / 数学一 301 / 408
- 规划区间：2026-11-03 → 2027-12-26
- 初试日期：2027-12-25（周六）— 2027-12-26（周日）
- 目标分：政治 70 + 英语 70 + 数学 120 + 408 115 = **375**
- 计划规模：**60 周 / 419 天 / 2162 项任务 / 约 1720 小时**
- 同时包含：六级（2026-12-19 试水，2027-06-19 主目标）、每日算法竞赛、每月与节假日休息

完整文字版规划见 [`学习规划.md`](./学习规划.md)。

**在线访问：<https://luvisage.github.io/study/>**

## 打开方式

这是纯静态页面，没有构建步骤、没有第三方依赖。

### 方式一：在线访问

打开 <https://luvisage.github.io/study/>，手机和电脑都能用，进度保存在各自浏览器里。

### 方式二：直接打开

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。

### 方式三：本地服务（推荐）

在项目目录运行：

```bash
python -m http.server 8787
```

然后访问 <http://127.0.0.1:8787/>。

> 推荐本地服务，是因为部分浏览器会限制 `file://` 页面里的下载、剪贴板等能力。直接双击也能正常打卡。

## 页面功能

| 视图 | 内容 |
|---|---|
| **今日** | 今天的日期、阶段、主题、课程任务、预计时长、完成进度、连续打卡、下一次休息 |
| **日历** | 按月查看 419 天，标出全休 / 半休 / 六级 / 初试；点任意一天查看或补卡，并写下当天记录 |
| **规划** | 7 个阶段、关键节点、每周节奏、六科策略、休息规则、目标分 |
| **数据** | 连续天数、累计专注、本周完成率、日期进度、60 周热力图、分科进度、月度投入、番茄统计 |

其他：

- 任务勾选自动保存，刷新页面不丢失
- 每日任务只写「做什么」，具体章节与资料放在「本周主线」，方便按状态调整
- 必做项完成 60% 即算当天达标；全部完成会触发一次彩纸动画
- 全休日自动打卡，不需要手动勾选
- 未来日期只能查看，不能提前打卡；过去日期可以补卡
- 每天可在日历里写一条 160 字以内的记录，自动保存在本机；有记录的日期会显示一个小红点
- 页面跨天会自动切到新一天：零点后、切回标签页或重新打开页面时都会检查
- 右下角番茄钟：专注 25 / 短休 5 / 长休 15，支持暂停、重置、完成提示音，并统计今日与累计番茄数
- 深浅色主题切换
- 进度、每日记录和番茄统计可一起导出为 JSON、导入恢复、一键清空
- 快捷键 `Alt + 1/2/3/4` 切换四个视图
- 规划页支持打印 / 存 PDF（打印时只输出规划内容）

## 数据保存在哪里

所有进度只保存在当前浏览器的 `localStorage`，键名：

```text
yantu408.state.v1
```

换浏览器、换设备、清理浏览器数据都会丢失。建议每周日复盘后到「数据」页导出一次 JSON，文件名会自动带日期。

导出的 JSON（`version: 2`）包含三部分：任务勾选、每日记录、番茄统计。导入旧版（`version: 1`）文件也能识别，只恢复任务勾选。

## 想自己改计划

- 改阶段、目标分、关键日期、语录：`assets/plan.js`
- 改某一周的主题与章节：`assets/weeks-a.js` / `assets/weeks-b.js`
  - 每行格式：`[周号, 阶段, 主题, 数学, 科目A, 章节A, 科目B, 章节B, 英语, 六级, 算法, 政治, 备注]`
- 改每天的任务类型、时长、文案：`assets/core-day.js`
  - `TIME` 控制各阶段各任务时长
  - `DETAIL` 控制任务说明
  - 周一到周六的任务在 `buildNormal`
  - 半休日在 `buildLight`
  - 六级日、考前日、初试日在 `buildCET` / `buildPre` / `buildExam`
- 改全休 / 半休规则：`assets/core-base.js` 里的 `FULL_EXTRA`、`LIGHT_EXTRA` 和 `isFullRest` / `isLightRest`

改完直接刷新页面即可，不需要编译。

## 日期说明

考研初试按 **2027 年 12 月最后一个周末** 估算为 2027-12-25 / 26；六级按常规考试日估算为 2026-12-19 与 2027-06-19；报名、大纲、准考证等日期均为**往年规律估算**。实际日期以教育部、学信网、学校和教务通知为准，关键节点请提前设提醒。

## 使用建议

1. 每天早上打开「今日」，只看今天的任务，不翻后面。
2. 先做必做项；状态差的日子完成 60% 就算达标，不要断签。
3. 周六周测/套卷必须计时，做完立刻订正。
4. 每完成一个 25 分钟专注块，用右下角番茄钟记一次；休息就真的离开桌子。
5. 每周日复盘后导出一次进度。
6. 休息日真的休息。计划里已经留好了，不需要内疚。

> 计划是地图，不是枷锁。把今天过好，就是最好的长期主义。
